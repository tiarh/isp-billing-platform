# Security

This repository is a read-only snapshot with fictional data. It does not contain real
credentials or customer data.

If you find a vulnerability, please do not open a public issue. Use GitHub private
vulnerability reporting: open the **Security** tab of this repository and choose
**Report a vulnerability**.

If you find something that looks like a real secret or real personal data in this
repository, report it the same way so it can be removed.

Replies are not guaranteed, but reports are read.
